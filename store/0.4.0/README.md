# Pocket Arcade 0.4.0 (staged, not published)

Pocket Artillery and Space Salvage 0.4.0 add Pebble Time, Pebble 2, Pebble 2 Duo and
Pebble Time Round to Time 2 and Round 2. The frozen packages are in
`release/pocket-artillery/0.4.0/` and `release/space-salvage/0.4.0/`, each with native
reports for all six watches.

The store kits (five native screenshots and a banner per watch, listing text, release
notes and a proposed description that names every watch) live in the Ambient Time
repository at `appstores/pebble/store/pocket-artillery/` and
`appstores/pebble/store/space-salvage/`, laid out for `scripts/publish-pebble-update.py`.
Publication waits for Luke's go-ahead. The other four games stay at 0.3.1 on Time 2 and
Round 2.
