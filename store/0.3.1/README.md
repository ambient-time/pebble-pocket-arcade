Six public games for Pebble Time 2 and Round 2.

- [Pocket Artillery](https://apps.repebble.com/f3f15b3aa8e84a9ba94799c2)
- [Space Salvage](https://apps.repebble.com/68aa4add5dd34617aa03fab8)
- [Dungeon Pinball](https://apps.repebble.com/af9f35b5deee4c228f985ee6)
- [Train Dispatcher](https://apps.repebble.com/7740b7c3376d451ba5e451bb)
- [Pocket Ecosystem](https://apps.repebble.com/62e07532be45454185e1fa3c)
- [One-Screen Tactics](https://apps.repebble.com/bd8c735ad2e5423db857d736)

Each Store download matches the frozen release PBW. Both saved media panels contain a native GIF, four stills and a banner. The original owner descriptions and app identities are retained.

The exact packages passed native emulator checks. Physical-watch touch, readability and battery testing remain open.
