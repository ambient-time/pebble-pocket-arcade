# Pocket Arcade for Pebble

Six native watch games by Luke Steuber, built for Pebble Time 2 and Pebble Round 2.

- Space Salvage: pilot a tug, retrieve cargo and escape a dangerous wreck field.
- Pocket Artillery: aim across destructible terrain in short tank duels.
- Dungeon Pinball: fight monster bumpers, unlock gates and defeat a table boss.
- Train Dispatcher: switch tracks and route distinct trains to matching stations.
- Pocket Ecosystem: cultivate plants, grazers and predators through changing seasons.
- One-Screen Tactics: defend an objective through five telegraphed enemy turns.

Each is a separate installable app. Shared code owns persistence, pause menus,
small-screen drawing helpers and packaging; each game owns its rules and controls.

Development is in progress. See `PLAN.md` for acceptance requirements and verified
completion status. A source file or build alone does not mean a game is finished.
